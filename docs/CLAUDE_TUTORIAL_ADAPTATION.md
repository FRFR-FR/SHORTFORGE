# Claude animated-shorts tutorial: SHORTFORGE adaptation

## Supplied tutorial

- Video: How to Make Viral Animated Shorts Using Claude (Full Workflow): https://youtu.be/OtbLL6OBNE4
- Companion source: https://github.com/mromidev/claude-animated-shorts
- Companion source licence: MIT (see the companion repository LICENSE).

The companion repository describes a workflow involving reference research, a written style bible, an original story, shot planning, rendering, specialist reviews and iterative frame QA. This file records the adaptation of those general methods to SHORTFORGE.

## Adopted principles

1. Research before storyboarding.
2. Write a reusable style bible from aggregate production traits.
3. Use a clear hook, escalating visual beats, explanation/payoff and a memorable ending.
4. Separate camera, world, materials, characters and post-production review.
5. Inspect stills/contact sheets repeatedly and keep numeric reports.
6. Use specialist reviews with explicit findings.
7. Keep each new story, character set, voice, design and sequence original.

## SHORTFORGE-specific architecture

Blender remains the final renderer; Three.js remains optional previs; FFmpeg remains the encoder. Existing 30 fps vertical settings, avatar system, asset provenance, frame QA, GitHub Release publishing and seven review roles remain authoritative. Reference Lab reports numeric CSV/JSON measurements and does not import or retain the companion project's reference frames or example story.
