# Per-short delivery checklist

## Story assets
- [ ] Final premise and intended audience
- [ ] Word-for-word narration script, or “no narration”
- [ ] Timestamped beat sheet
- [ ] Scene-by-scene visual production plan (environment, character action, camera, props, transition, sound)
- [ ] Style-bible version recorded
- [ ] Reference research summary completed where requested

## Render assets
- [ ] Smoke render passed before production render
- [ ] MP4 encoded at 30 fps in 9:16
- [ ] Optional captions SRT supplied and checked for timing/readability
- [ ] Optional Kokoro narration checked for pronunciation and sync
- [ ] No background music unless requested
- [ ] QA report and contact sheet saved
- [ ] Render manifest saved

## Specialist approvals
- [ ] Story editor
- [ ] Director of photography
- [ ] Character animator
- [ ] Environment/continuity supervisor
- [ ] Art director
- [ ] Dialogue/sound editor
- [ ] Technical QA/rights reviewer

## Delivery
- [ ] MP4 opened and visually spot-checked
- [ ] Audio checked on headphones/speakers where present
- [ ] Release URL verified if publishing was requested
- [ ] Known limitations disclosed
