# SHORTFORGE production brief

Create an original vertical animated short for 9:16 viewing at 30 fps. Use the project's style bible and these constraints:

- Original premise, script, dialogue, characters, props and environment.
- A clear first-second hook, purposeful visual changes approximately every 2–4 seconds, escalating action and an earned ending.
- Design each environment for the scene's actual action rather than using an unrelated generic background.
- Plan camera moves and character blocking before rendering; preserve safe space for captions.
- Use anticipation, grounded contacts, readable silhouettes, overlap and follow-through.
- Optional Kokoro narration only when the project requests it; no music by default.
- Do not copy another creator's scripts, characters, art, exact shot sequence, branded elements or protected audio.

Deliver:
1. A word-for-word narration script (or explicitly state “no narration”).
2. A beat sheet with timestamps.
3. A shot list with environment, camera, character action, prop movement and sound notes.
4. A style-bible delta if the project intentionally changes the visual language.
5. The seven specialist review reports.
6. A verified MP4 plus frame-QA report and contact sheet.
