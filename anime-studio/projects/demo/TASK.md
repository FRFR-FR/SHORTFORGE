# NEON VEIL — Run the Last Light

A 15-second, original, horizontal 16:9, 30fps 2.5D anime action sequence.

This episode is authored directly in Three.js and original SVG artwork. No Claude agent or Anthropic API key is involved in its creative production.

Visual intent:
- premium cyberpunk anime illustration with expressive character face, detailed outfit and readable anatomy
- layered, dense neon megacity plates: skyline, towers, signs, cables, rain, speed, vehicles, wet street reflections
- 2.5D character animation with articulated torso/head, upper/lower arms, upper/lower legs and flowing scarf
- a mechanical hunter drone with animated optic, rotating rings, scan cone and stabilizer fins
- cinematic camera tracking, tilt, push-in, attack follow and impact composition
- cyan photon blade, energy slash arc, speed streaks, rain and floating embers

All art is original to this project. Do not copy existing anime characters, logos, costumes, props, frames, designs or exact scene choreography.
